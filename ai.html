Unpacking ChatGPT Work: the Agent for a Billion Users

OpenAI released ChatGPT Work in July, an agent for knowledge work that reached 10 million users in three weeks and will merge with the main ChatGPT app by year-end, positioning it as the template for how the platform's billion-plus weekly users will soon interact. Work runs on persistent cloud VMs (8 CPUs, 20GB RAM for Pro) with full browser control and integrations across Slack, email, Drive, and hundreds of plugins, marking mainstream adoption of what was previously niche agent infrastructure. The product's fusion of chat, coding, and autonomous task execution suggests OpenAI is betting that knowledge workers want stateful, always-on agents rather than conversational turn-taking.
